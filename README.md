# 🩺 呼吸道周报 · 本周流行什么

> 把中国疾控中心每周的呼吸道传染病监测、流感周报和每月法定传染病报告，翻译成一页看得懂的「本周流行什么」

**🌐 在线访问：[https://climb0516.github.io/health-weekly/](https://climb0516.github.io/health-weekly/)**

---

## 功能

- **一句话结论**：本周门诊头号病原体、阳性率及较上周变化；南方 / 北方流感处于低 / 中 / 高流行水平（引用官方原话）
- **要点四格**：流感样病例占门诊比例（南北方）、流感阳性率、新冠阳性率、流感样病例暴发起数
- **病原体排行**：门急诊和住院两组，11 种病原体（新冠、流感、合胞病毒、腺病毒、人偏肺、副流感、普通冠状、博卡、鼻病毒、肠道病毒、肺炎支原体）阳性率横条，标出较上周升降
- **近一年走势**：可切换病原体或流感样病例比例，每周一个点，悬停看数值；一眼看出流感季是否来了
- **谁更容易中招**：南北方各自排名前三的病原体
- **官方分析与健康提示**：原文摘录，不自行编写医疗建议
- **每月法定传染病**：流感、手足口、感染性腹泻（含诺如）、水痘、猩红热、新冠的近两年月度小走势，以及当月发病数前十和环比
- 右侧：流感监测周报（甲 / 乙型、H3N2 / H1N1 占比与概要）、更新节奏、来源状态
- 深色 / 浅色主题，手机适配

数据仅供了解流行趋势，不构成医疗建议；身体不适请及时就医。

## 数据来源（均为中国疾病预防控制中心官网）

| 栏目 | 频率 | 解析内容 |
|---|---|---|
| [全国急性呼吸道传染病哨点监测情况](https://www.chinacdc.cn/jksj/jksj04_14275/) | 每周（周四前后） | 流感样病例百分比（南北方）、表 1 各病原体阳性率及较上周、表 2 南北方前三、分析与健康提示 |
| [流感监测周报](https://www.chinacdc.cn/jksj/jksj04_14249/) | 每周 | 流行情况概要、甲 / 乙型及亚型占比、暴发起数 |
| [全国法定传染病疫情情况](https://www.chinacdc.cn/jksj/jksj01/) | 每月（中旬发布上上月） | 统计表中各病种发病数、死亡数 |

**限制**：
- 2026 年 4 月以前的哨点报告没有表 1，只在正文写前三位病原体，所以走势图早期只有上榜的病原体有点
- 流感周报的具体阳性率在 PDF 附件里，只取网页上的文字概要
- 报告格式改版时解析会失败，页面沿用上一次的数据并在来源状态里标出

## 技术架构

```
GitHub Actions（每天北京时间 10:05 / 手动 / 修改爬虫后 push）
  ↓ python scraper.py（只用标准库）
  ↓ 三个栏目的列表页 → 详情页解析；已解析过的期次按 URL 缓存在 data.json，不重复请求
  ↓ 首次运行补抓近 60 周、36 个月历史
  ↓ 写入 data.json 并 commit（updated 每次都变 = 心跳，防止定时任务 60 天不活跃被停用）
       ↓
GitHub Pages（index.html 读取 data.json 渲染）
```

### data.json 结构

```
{
  "updated": "...",
  "weeks": [ {                       // 新的在前，最多 60 周
    "year": 2026, "week": 41, "period": ["2026-10-05", "2026-10-11"], "url": "...",
    "ili": 3.8, "ili_south": 4.6, "ili_north": 3.0,
    "outpatient": { "流感病毒": { "rate": 13.6, "chg": 2.4 }, ... },   // 门急诊阳性率 %，chg 为较上周百分点（老报告为 null）
    "inpatient":  { ... },                                            // 住院
    "region": { "south": { "out": [前三], "in": [前三] }, "north": {...} },
    "level": { "south": "中流行水平", "north": "低流行水平" },
    "analysis": "官方分析原文", "tips": ["（1）…", ...]
  } ],
  "flu": { "title", "url", "until", "summary", "a_pct", "b_pct", "h1n1_pct", "h3n2_pct", "outbreaks" },
  "months": [ { "month": "2026-08", "url", "total", "deaths", "diseases": { "流行性感冒": [发病, 死亡], ... } } ],
  "sources": [ { "name", "ok", "count", "error?", "updated" } ]
}
```
